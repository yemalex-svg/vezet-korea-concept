# Везёт Корея — концепт сайта

Кликабельный прототип сайта доставки посылок из Кореи: главная со скролл-видео и внутренние страницы (страны, тарифы и калькулятор, выкуп, бизнесу, пункты, отслеживание, вопросы, о компании, контакты, личный кабинет, документы).

Цены и сроки взяты из материалов клиента и требуют подтверждения. Кабинет и админка работают на демо-данных.
