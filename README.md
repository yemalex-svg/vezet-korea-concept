# Везёт Корея — концепт сайта

Кликабельный прототип сайта доставки посылок из Кореи: главная со скролл-видео и внутренние страницы (страны, тарифы и калькулятор, выкуп, бизнесу, пункты приёма, отслеживание, вопросы, о компании, контакты, документы).

Тарифы и факты — по ТЗ клиента от 02.11.2026. Расчёт в калькуляторе демонстрационный, отслеживание работает на демо-номере RU-KVA-1365-01-47.
